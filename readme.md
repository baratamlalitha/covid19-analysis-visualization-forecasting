# 🦠 COVID-19 Data Analysis, Visualization & Time-Series Modeling

## 📌 Project Overview

This project analyzes COVID-19 data to study infection and recovery trends over time. It also applies time-series analysis to understand how the pandemic evolves and identify patterns in disease spread.

---

## 🎯 Objectives

* Analyze global COVID-19 data
* Calculate daily infection and recovery rates
* Perform time-series analysis on pandemic trends
* Visualize data using graphs
* Derive meaningful insights from temporal data

---

## 📊 Features

* Data preprocessing and cleaning using Pandas
* Aggregation of data based on dates
* Calculation of daily new cases (infection rate)
* Visualization of infection and recovery trends
* Time-series trend analysis of COVID-19 spread

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

---

## ⏳ Time-Series Analysis

* Converted date column into proper datetime format
* Grouped data by date to analyze trends over time
* Calculated daily changes in confirmed and recovered cases
* Visualized time-based trends to understand infection patterns

---

## 📂 Dataset

The dataset contains:

* Confirmed cases
* Recovered cases
* Death cases
* Date-wise global data

---

## 📈 Output / Results

* Visualized daily infection rate trends
* Visualized recovery rate patterns
* Identified time-based patterns in COVID-19 spread

---

## ▶️ How to Run the Project

1. Download the dataset and project files
2. Open the Jupyter Notebook
3. Run all cells step by step

## 🧠 Key Insights

* Infection rate shows how fast the disease spreads
* Recovery rate helps understand healthcare response
* Time-series analysis reveals trends and waves in the pandemic
